CODE 2 CHILL - Enhanced Frontend

Requirements: Node.js 18+ and npm

Run locally:
1. Extract this ZIP.
2. Open a terminal in the frontend folder.
3. Run: npm install
4. Run: npm run dev
5. Open the local URL printed by Vite (usually http://localhost:5173/).

Enhancements:
- Hero gradient reacts to mouse movement, with a soft cursor-following glow.
- Navigation links have animated active/hover states and a refined mobile dropdown.
- Navbar brand displays CODE 2 CHILL.
- Existing routes, authentication, dashboard and API integration code are preserved.
